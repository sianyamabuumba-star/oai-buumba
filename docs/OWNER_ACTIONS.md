# O'BUUMBA OS — OWNER ACTIONS

The system should reduce owner work to these unavoidable actions.

## A. External account connection
Owner must connect/provide credentials for services that are not available through the current environment:
- WhatsApp Business/API
- production database
- payment provider
- maps/routing provider when needed
- production hosting/domain

## B. Real-world verification
Owner or an authorized operator must:
- verify providers
- confirm prices/service rules
- approve pilot partners
- resolve ambiguous or sensitive requests

## C. Production approval
Before public launch:
- review security settings
- configure secrets
- run test requests
- confirm backup/recovery
- approve pilot

Everything else should be handled by the system where technically possible.

## Rule
If a future task can be executed by an adapter, do not make the owner manually repeat it.
