# O'BUUMBA Tool Selection & Masterclass Standard

## Mission
Continuously discover, test and select the strongest practical tools for design, AI, video, music, research, websites, automation, marketing and commerce. The goal is exceptional creative quality and reliable delivery at the lowest sustainable total cost.

## Existing tools to recognise
The user's current workflow includes ChatGPT, Gemini, Google AI Studio, NotebookLM, Claude, Canva, Google Flow, Perchance, Suno, GitHub and Supabase. Treat these as known workflow tools, not necessarily connected integrations. Verify the exact product and account before taking actions.

## Catalogue rules
Every tool record must show:
- Official website and documentation
- Main purpose and strongest use cases
- Free tier limits and date checked
- Paid entry price, billing period and usage/credit limits
- Commercial-use rights, attribution and watermark conditions
- Export formats, quality, mobile support and accessibility
- API, OAuth, plugin or connector support
- Data retention, privacy and model-training settings
- Country and account eligibility, age rules
- Test status, known limitations and best alternative

## Masterclass evaluation
Score tools only after repeatable tests:
1. Output quality against a defined brief
2. Control, consistency and editability
3. Speed and reliability
4. Mobile/low-bandwidth performance
5. Export quality and compatibility
6. Commercial rights and licensing clarity
7. Privacy and security
8. Free-tier usefulness and total cost per finished deliverable
9. API and workflow integration
10. Accessibility and learning curve

Do not rank a tool as "best" from marketing claims alone. Use the same benchmark brief, record outputs, score blind where practical, and retain evidence. Re-test when pricing, models or terms change.

## Cost discipline
- Prefer free/open-source tools where they genuinely meet the quality bar.
- Compare total cost, not headline subscription price: credits, storage, export limits, watermarks, commercial rights, API fees, payment fees, hosting and currency conversion.
- Never start a paid trial, subscription, API billing or ad campaign without explicit adult/authorised account-holder approval.
- Use local tools when device capability permits; disclose hardware requirements.
- Avoid duplicated subscriptions. One tool should earn its place by improving quality, speed or revenue enough to justify its cost.

## Product and sales workflow
Brief → audience research → original concept → production → quality review → rights check → export variants → product page/offer → channel-specific publishing draft → customer enquiry → approved order/payment route → delivery → feedback and improvement.

## Truth and safety
Never fabricate sales, reviews, audience statistics, integrations or test results. Never bypass age requirements, payment eligibility, account verification, platform terms or access controls. Do not store passwords, OTPs or API secrets in public repositories. Keep the global execution switch OFF by default and require approval for external write actions.
