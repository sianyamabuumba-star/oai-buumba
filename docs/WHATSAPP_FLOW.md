# WhatsApp Concierge Flow

INBOUND MESSAGE → identify customer → classify intent → extract date/time/location/budget/party size → search verified providers → rank matches → present concise options → confirm choice → verify live availability → create booking/request → send confirmation → log interaction.

Escalate when confidence is low, availability cannot be verified, a request is outside the directory, payment fails, a provider rejects the request, or the request is sensitive/unusually valuable.

The AI must never fabricate a provider, price, availability or booking.
