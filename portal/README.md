# O'BUUMBA Intelligence Portal — foundation prototype

Open `portal/index.html` in a browser to preview the portal interface.

## Included
- Premium responsive O'BUUMBA dashboard
- Local source capture (HTTP/HTTPS URLs)
- Search, remove and JSON export
- Skills/tools catalogue foundation
- Workflow catalogue foundation
- Explicit status for features that are not yet connected

## Important
This is a front-end foundation, not a production account system. Sources and notes are saved only in the current browser's localStorage. There is no login, cloud sync, server-side URL retrieval, AI analysis or live connector yet. Do not enter secrets or sensitive information.

See [MVP implementation notes](../docs/INTELLIGENCE_PORTAL_MVP.md) for the staged implementation and security requirements.
